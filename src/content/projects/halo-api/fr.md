## API et films du mode Cinéma {#theater}

halo_api est une bibliothèque Rust pour les API de Halo Infinite et l’analyse hors ligne des films du mode Cinéma. L’inspecteur de paquets ci-dessus affiche les données décodées d’une partie enregistrée.

L’[article sur la rétro-ingénierie du mode Cinéma](https://spencer.imbleau.com/blog/ai/rust/2026/09/14/halo-infinite-theater-format-astra.html), en anglais, décrit l’enquête, des enregistrements contrôlés à la comparaison d’une relecture reconstruite avec la partie d’origine.
